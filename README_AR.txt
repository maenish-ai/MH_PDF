إصلاح استيراد PDF من صفحات الويب — MH_PDF

ارفع الملفين إلى نفس المسارات في مستودع GitHub:
core/WebPdfImporter.cpp
ui/PdfImportDialog.qml

الآن زر Download يقبل رابط صفحة HTML ويحوّله إلى اكتشاف ملفات PDF بدلاً من إلغاء العملية. عند ظهور النتائج، اضغط على اسم الملف المطلوب لتنزيله وفتحه. يدعم أيضًا روابط PDF المباشرة، والترويسات الموزعة على دفعات صغيرة، ويتجنب فحص محتوى إعادة التوجيه كملف PDF.

الاختبار النهائي: GitHub Actions لبناء Windows وAndroid، ثم تجربة رابط صفحة nccd.gov.jo.
