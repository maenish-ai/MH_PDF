# MaenPDF 7.5.0 Keyboard Shortcuts

MaenPDF uses an **Acrobat-familiar** shortcut profile so people coming from Adobe Acrobat do not need to relearn common PDF navigation and tool commands. Standard Windows shortcuts are preserved where possible. Single-key tool shortcuts can be turned off in **Preferences**.

## File and editing

| Shortcut | Action |
|---|---|
| Ctrl+N | New document/tab |
| Ctrl+O | Open PDF |
| Ctrl+S | Save |
| Ctrl+P | Print |
| Ctrl+F | Find text |
| Ctrl+Z | Undo |
| Ctrl+Y / platform Redo | Redo |
| Ctrl+C | Copy selected PDF text; otherwise copy current page |
| Delete / Backspace | Delete selected MaenPDF text/form overlay object |
| Ctrl+Shift+D | Delete current page |
| Ctrl+Shift+T | Add blank page |
| Ctrl+Shift+I | Insert/combine another PDF |
| Ctrl+W | Close current document tab (with unsaved-change guard) |

Delete and Backspace are deliberately disabled while typing in a text field, so normal text editing is never hijacked by a global shortcut.

## View and navigation

| Shortcut | Action |
|---|---|
| Ctrl+= or Ctrl++ | Zoom in |
| Ctrl+- | Zoom out |
| Ctrl+0 | Fit page |
| Ctrl+1 | Actual size (100%) |
| Ctrl+2 | Fit width |
| Ctrl+L | PDF Full Screen Mode (document only; no menus or sidebars) |
| Ctrl+Shift+N | Go to page |
| Ctrl+Tab / Ctrl+Shift+Tab | Next / previous document tab |
| F4 | Show/hide Pages sidebar |
| Page Up / Page Down | Previous/next screen |
| Ctrl+Page Up / Ctrl+Page Down | Previous/next page |
| Left / Right | Previous/next page |
| Home / End | First/last page |
| Ctrl + mouse wheel | Zoom |
| Mouse wheel | Scroll document continuously |

## Tools

| Shortcut | Tool |
|---|---|
| V | Pointer / Select |
| H | Hand / Pan |
| T | Insert text |
| U | Highlight selected text/area |
| Shift+U | Highlight Pen (freehand) |
| D | Draw |
| C | Crop |
| Shift+Y | Redact |
| Esc | Cancel current pending tool operation and return to Pointer |

Single-key shortcuts are ignored while a text input has keyboard focus.

## Application

| Shortcut | Action |
|---|---|
| Ctrl+K | Preferences |
| Ctrl+Shift+P | MaenPDF Command Palette |

The Acrobat-familiar choices are based on Adobe Acrobat's published desktop shortcut conventions. MaenPDF keeps Ctrl+Shift+P for its Command Palette so Ctrl+K can retain the Acrobat-style Preferences behavior.
