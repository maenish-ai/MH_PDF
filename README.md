# MaenPDF

MaenPDF is a free, open-source PDF reader and editor for Windows and Android, with English and Arabic interfaces. It supports viewing, searching, annotating, organizing and printing PDFs. Windows builds from version 7.5.8 include local OCR for Arabic and English to create searchable copies of scanned documents.
