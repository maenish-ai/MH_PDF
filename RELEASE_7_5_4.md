# MaenPDF v7.5.4
- Import PDF from Internet: clicking a PDF row selects/deselects it; Download downloads the selected PDF only; without a selection, Download All downloads all discovered PDFs sequentially.
- Reset aborts an active request, clears URL, discovered list, selection, queue, progress and result dialogs, without deleting previously saved PDFs.
- Existing updater and localization changes retained. Windows installer update still requires user approval; automatic post-install relaunch is not guaranteed.
- CI source audits and local static checks are not a substitute for installed Windows end-to-end tests.
